Privacy Policy

Last updated: 2026-10-08

Channel Uploader is a personal tool used only by the owner of the YouTube channels it uploads to.

What it accesses

With the owner's permission through Google OAuth, the tool uses the YouTube Data API to read the owner's channel and upload list, upload videos, set titles, descriptions, publish times and captions, and add translated titles and descriptions.

Where data is kept

The OAuth token is stored only on the owner's own PC. The tool has no server and does not collect, sell, or share any data with third parties. Google user data is used only to perform the uploads described above.

How to revoke access

Access can be removed at any time from Google Account → Third-party connections.

Contact

Open an issue in the GitHub repository.
